## 本地编辑与查看

1. 在系统文件资源管理器中双击根目录的 `start.bat`，或在 VS Code 使用“终端 → 运行任务 → 启动项目（Windows）”。
2. 在上表找到个人 HTML，使用编辑器修改介绍与样式，保存为 UTF-8。
3. 回到首页点击“刷新成员介绍”，检查卡片与“独立预览”的完整页面。
4. 点击“排序演示”，查看该成员的源码和数组变化。
5. 补充新成员或更换源码路径时，同步更新 `members.json`；个人介绍文件按 01–18 连续编号，排序源码文件名保持原样。

完整启动与使用步骤见 [使用指南](../STUDENT_GUIDE.md)。公共样式 `card.css` 由项目统一维护，个人样式写在自己的 HTML 中。
