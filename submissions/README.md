# 排序源码

这里保留 17 位现有成员的原始排序程序，供个人排序演示页读取与运行，也方便后续继续修改。

成员与源码的对应关系统一保存在根目录的 `members.json`，完整表格见 [成员与排序源码](../members/README.md)。首页每张成员卡片都有对应的排序展示入口；“新成员”尚未配置源码。

## 查看演示

1. 使用根目录的 `start.bat` 或 `python server.py` 启动项目。
2. 在首页找到成员，点击“排序演示”。
3. 在演示页阅读对应源码，运行并查看排序可视化。

大部分源码为 Python；`计2602_谢宇轩.cpp` 使用 C++，运行需要 G++。演示依赖项目的本地执行服务，直接双击 HTML 或使用其他静态服务无法运行源码。

## 后续维护

更新程序时可编辑原源码文件，保存后重新打开对应成员的排序页并运行。新增或重命名文件时，同时更新 `members.json` 的源码路径。

现有文件名保留原样，包括 `计2603_李嘉嬴.py` 的姓名写法，以及 `计2601_周钰山 .py` 在扩展名前的空格。原 `sorting.js` 与执行服务也保留供后续修改。

项目使用方式见 [使用指南](../STUDENT_GUIDE.md)。
